# Módulo de Usuários

Este módulo concentra a lógica de perfis e associação de usuários aos condomínios.

## Responsabilidades
- definir os perfis suportados: morador, sindico, porteiro, conselheiro e administradora;
- associar um usuário a um ou mais condomínios;
- fornecer contratos para uso em serviços e repositórios futuros.
